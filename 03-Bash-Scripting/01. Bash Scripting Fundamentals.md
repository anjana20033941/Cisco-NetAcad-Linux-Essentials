# 📜 Shell Scripting Basics

## Shell Script Definition

A text file containing a sequence of executable shell commands that are executed sequentially when the file is run.

```bash
sh test.sh
./test.sh
```

---

## Shebang (`#!`)

The first line of a script specifying the absolute path to the binary interpreter (e.g., `/bin/bash` or `/bin/sh`).

```bash
#!/bin/bash
```

---

## Script Permissions

Before executing a script directly using `./script.sh`, it must be granted execution permissions using `chmod`.

```bash
chmod +x ./test.sh
```

---

## Variables

Variables store data for reuse without using spaces around the `=` sign during assignment. Use `$` to access/interpolate the variable's value.

```bash
ANIMAL="penguin"
echo "My favorite animal is a $ANIMAL"
```

---

## Command Substitution

Assigns the standard output of a shell command to a variable using backticks (`` `command` ``).

```bash
CURRENT_DIRECTORY=`pwd`
```

---

## User Input (`read`)

Prompts and accepts input from standard input (keyboard) and saves it into a variable.

```bash
read NAME
```

---

## Special & Positional Variables

Pre-defined shell variables used to capture execution parameters and statuses:

* `$1`, `$2`, ... : Positional argument parameters passed to the script.
* `$0` : Returns the name of the script itself.
* `$?` : Returns the exit status code of the last executed command (0 = success, 1-255 = error).

---

## `exit` Command

Terminates script execution and explicitly returns a custom exit status code to the caller environment.

```bash
exit 1
```

---

## `if / else` Branching

Executes code blocks based on the exit code status (0 = true) of a test or command.

```bash
if grep -q root /etc/passwd; then
  echo "root exists"
else
  echo "root missing"
fi
```

---

## `test` Command & `[ ]` Syntax

Evaluates conditional expressions for files, numbers, and strings. The bracket `[ ]` syntax is an alias for the `test` command.

* `-f` : Checks if a file exists.
* `-d` : Checks if a directory exists.
* `-eq`, `-ne`, `-lt`, `-gt` : Numeric comparison operators (equal, not equal, less than, greater than).
* `=`, `!=` : String comparison operators.
* `-a` / `-o` : Logical AND / OR operators.

```bash
if [ -f /tmp/foo ]; then
  echo "File exists"
fi
```

---

## `elif` & `case` Statements

Used for multi-directional branching based on dynamic variable values or pattern matches.

```bash
# if / elif / else syntax
if [ "$1" = "hello" ]; then
  echo "hello yourself"
elif [ "$1" = "goodbye" ]; then
  echo "goodbye"
else
  echo "unknown"
fi

# case syntax
case "$1" in
  hello|hi)
    echo "hello yourself"
    ;;
  goodbye)
    echo "goodbye"
    ;;
  *)
    echo "unknown"
    ;;
esac
```

---

## `for` Loop

Iterates over a finite collection of items, strings, or file globs.

```bash
for S in servera serverb serverc; do
  echo "Processing $S"
done

for FILE in *; do
  echo "File: $FILE"
done
```

---

## `while` Loop

Repeats execution continuously as long as the specified test condition remains true. Arithmetic updates are handled using `$(( ... ))`.

```bash
i=0
while [ $i -lt 10 ]; do
  echo $i
  i=$(( $i + 1 ))
done
```
