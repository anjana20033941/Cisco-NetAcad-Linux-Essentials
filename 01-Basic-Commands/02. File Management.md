# Linux Commands Reference - File Management & Archiving

## 1. File & Directory Management

### Managing Files
- `touch filename` - Create an empty file (0 bytes) or update timestamps.
- `rm filename` - Permanently delete a file.
- `rm -i filename` - Delete a file with confirmation (Interactive mode for safety).
- `mv old_name new_name` - Rename or move a file/directory.

### Managing Directories
- `mkdir dirname` - Create a new directory.
- `rmdir dirname` - Remove an **empty** directory.
- `rm -r dirname` - Recursively remove a directory and all of its contents.
- `rm -ri dirname` - Interactively remove a directory and its contents safely.

## 2. File Archiving (`tar`)

The `tar` (Tape Archive) command is used to combine multiple files/folders into a single file.

### Primary Modes
- `-c` : **Create** a new archive.
- `-x` : **Extract** contents from an archive.
- `-t` : **List** the contents of an archive without extracting.

### Archive Options & Flags
- `-f` : Specify the filename of the archive (**Must be the last flag before the filename**).
- `-v` : **Verbose** mode (shows progress/files being processed).
- `-z` : Compress/Decompress using **`gzip`** (`.tar.gz` or `.tgz`).
- `-j` : Compress/Decompress using **`bzip2`** (`.tar.bz2` or `.tbz`).
- `-r` : **Append** files to an existing uncompressed `.tar` archive.

### Common `tar` Command Examples
```bash
# Create an uncompressed tarball
tar -cf backup.tar file1 file2

# Create a gzip compressed tarball (.tar.gz)
tar -czf backup.tar.gz /path/to/directory

# Create a bzip2 compressed tarball (.tar.bz2)
tar -cjf backup.tar.bz2 /path/to/directory

# List contents of a compressed archive
tar -tzf backup.tar.gz
tar -tjf backup.tar.bz2

# Extract a gzip archive verbosely
tar -xzvf backup.tar.gz

# Extract specific folder/file from archive
tar -xzf backup.tar.gz home/user/file.txt

# Append a file to an existing tarball
tar -rvf backup.tar /etc/hosts
