# 🔀 Command Control Operators

Control operators allow you to chain multiple commands together based on the execution result of the previous command.

---

## 🔗 1. Logical AND (`&&`)

Executes `command2` **only if** `command1` succeeds (returns an exit status of 0).

```bash
command1 && command2
Behavior: If command1 fails, command2 will not run.

Example:

Bash
mkdir test_dir && cd test_dir
🔀 2. Logical OR (||)
Executes command2 only if command1 fails.

Bash
command1 || command2
Behavior: If command1 succeeds, command2 is skipped.

Example:

Bash
cd non_existing_folder || echo "Directory does not exist!"
