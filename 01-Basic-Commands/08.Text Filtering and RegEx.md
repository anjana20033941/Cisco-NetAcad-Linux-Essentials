# 🔍 `grep` & Regular Expressions

## `grep`

Filters lines in a file or stream output that match a specified pattern.

```bash
grep bash /etc/passwd
```

---

## `grep` Options

Key flags used to customize text filtering and matching rules:

* `--color` : Highlights matched text in red.
```bash
grep --color bash /etc/passwd
```

* `-c` : Outputs only the count of lines that match.
```bash
grep -c bash /etc/passwd
```

* `-n` : Displays the line numbers alongside matching lines.
```bash
grep -n bash /etc/passwd
```

* `-v` : Inverts the match to show lines not containing the pattern.
```bash
grep -v nologin /etc/passwd
```

* `-i` : Ignores case (case-insensitive search).
```bash
grep -i the newhome.txt
```

* `-w` : Matches whole words only.
```bash
grep -w are newhome.txt
```

---

## Regular Expressions (RegEx) in `grep`

Special wildcards used inside patterns to perform advanced searches:

* `.` (Period) : Matches any single character except newlines.
```bash
grep 'r..f' red.txt
```

* `[ ]` (Square Brackets) : Matches a single character from a set or range.
```bash
grep '[0-9]' profile.txt
```

* `[^ ]` (Negated Set) : Matches any character not listed inside the brackets.
```bash
grep '[^0-9]' profile.txt
```

* `*` (Asterisk) : Matches zero or more occurrences of the preceding character or pattern.
```bash
grep 're*d' red.txt
grep 'ee*' red.txt
```

---

## `?` (Question Mark)

Matches zero or one occurrence of the preceding character or pattern (optional element). Requires `grep -E` (Extended RegEx).

```bash
grep -E 'colou?r' filename.txt
```

---

## `+` (Plus)

Matches one or more occurrences of the preceding character or pattern. Requires `grep -E` (Extended RegEx).

```bash
grep -E 're+d' red.txt
```

---

## `|` (Pipe / Alternation)

Acts as a logical OR operator to match either the pattern on the left or the right. Requires `grep -E` (Extended RegEx).

```bash
grep -E 'cat|dog' filename.txt
grep -E 'r(ee|oo)f' red.txt
```
